This project is an Excel-based Healthcare Multi-Dashboard Analysis built using a dataset of 10,000+ patient records.
The main goal of this project is to analyze hospital performance and patient trends using interactive dashboards for better decision-making.

This project simulates a real-time Data Analyst reporting system, providing insights related to demographics, admissions, departments, revenue, insurance, and discharge status.
